# Directives (Layer 1: What to do)

Standard Operating Procedures (SOPs) written in Markdown live here.

## Directive Template

Each directive should define:
- **Goal**: What needs to be accomplished
- **Inputs**: Required parameters, datasets, files, or environment variables
- **Execution Tools / Scripts**: Deterministic scripts in `execution/` to run
- **Outputs**: Deliverables (Google Sheets, Slides, etc.) or processed artifacts
- **Edge Cases & Failure Modes**: Known API limits, retries, and handling procedures
