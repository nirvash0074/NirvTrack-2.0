# NirvTrack AI Copilot & Financial Intelligence Engine

A comprehensive guide for engineering, prompt-designing, and integrating client-side AI capabilities into NirvTrack via Google Gemini, local semantic heuristics, and merchant memory models.

---

## 1. Architectural Philosophy: Privacy, Determinism & Safe AI

AI in NirvTrack operates under three strict guardrails:
1. **Client-Side Privacy (BYOK)**: The user provides their Google Gemini API key or uses local edge endpoints. Private financial data is never sent to unauthorized third-party telemetry servers.
2. **Deterministic Fallbacks**: If the AI API fails, is rate-limited, or is offline, the app seamlessly falls back to local regex-based natural language parsing and static knowledge bases.
3. **Safe Creation with 1-Click Undo**: Any mutation generated by AI (new category, logged transaction, budget allocation) MUST be registered in `aiCreatedItemsUndoRegistry` so the user can roll it back in 1 click.

## 2. Dynamic Knowledge Introspection Engine (`[FEAT-68]`)

Rather than relying on static prompt instructions, NirvTrack dynamically introspects the active user's financial state to generate a real-time system context:

### Introspection Pipeline (`getDynamicFinancialContextPrompt()`)
- **Active Period**: Current month (`appState.activeMonth`) and days remaining.
- **Liquidity & Cashflow**: Planned income, total actual spend, remaining discretionary cash.
- **Top Overspending Categories**: Identifies envelopes exceeding 100% budget limit.
- **Active Wallets & Balances**: GCash, Maya, Bank, Cash holdings.
- **Goals & Bills**: Due bills within the next 7 days and active sinking fund progress.

### System Prompt Structure
```text
You are NirvTrack AI, an elite personal finance and budget optimization copilot.
You have real-time access to the user's active financial snapshot:
- Currency: {currency}
- Active Month: {activeMonth} ({daysRemaining} days left)
- Planned Income: {plannedIncome}
- Actual Expenses: {totalExpenses}
- Net Remaining: {remaining}
- Safe-to-Spend Per Day: {safeToSpend}
- Envelopes Over Budget: {overspentList}

Rules:
1. Be concise, direct, and mathematically precise.
2. Never hallucinate budget amounts or accounts not in the context.
3. Offer actionable, high-impact financial guidance (e.g. covering overspend via Surplus Sweeper).
```

## 3. Natural Language Expense Parsing Engine (`[QOL-QUICK-ADD]`)

The 1-line quick-add bar parses casual strings into structured transactions without opening complex modals.

### Example Inputs:
- `"Starbucks 185 yesterday credit card"` $\to$ `{ amount: 185, description: "Starbucks", date: "YYYY-MM-DD", paymentMethod: "Credit Card", category: "Dining Out" }`
- `"Groceries 2450.50 at SM Supermarket"` $\to$ `{ amount: 2450.50, description: "Groceries at SM Supermarket", category: "Groceries" }`
- `"₱450 Grab ride needs"` $\to$ `{ amount: 450, description: "Grab ride", budgetType: "needs", category: "Transportation" }`

### Parsing Priority:
1. **Currency & Amount Extraction**: Matches `(\$|₱|€|£)?\s*(\d+(?:\.\d{1,2})?)`.
2. **Date Extraction**: Identifies keywords (`today`, `yesterday`, day names, `YYYY-MM-DD`).
3. **Merchant Memory Lookup (`[FEAT-47]`)**: Matches description against historical transaction merchants. Automatically pre-fills the most frequently paired category and payment method!

## 4. Safe AI Creation & 1-Click Undo Architecture

Whenever AI creates or modifies state:
```javascript
const undoActionId = 'ai_undo_' + Date.now();
aiCreatedItemsUndoRegistry[undoActionId] = {
  type: 'batch_expense_create',
  data: createdItemsSnapshot,
  rollback: () => {
    // Reverse the mutation cleanly
    revertCreatedItems(createdItemsSnapshot);
    saveData();
    updateAllViews();
    showToast('AI changes undone successfully.', 'info');
  }
};

// Render toast with 1-click Undo button
showActionToast(
  `Created 3 transactions via AI.`,
  'Undo',
  () => aiCreatedItemsUndoRegistry[undoActionId].rollback()
);
```
